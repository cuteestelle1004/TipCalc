## Project Description
The Tip Calculator is an Android application developed using Kotlin and Jetpack Compose. It calculates tips, total bills and the amount each person should pay when sharing a bill.

## Personalized Values
- Default number of people (P): 4
- Rounding interval (Δ): $0.15
- Default and reset tip percentage (R): 7%

## Implemented Exercises
1. Exercise 1.1 – Splitting bills among multiple people.
2. Exercise 1.2 – Rounding up the per-person amount.
3. Exercise 1.3 – Clearing and resetting the calculator.

## Technologies
- Android Studio
- Kotlin
- Jetpack Compose

## How to Run
1. Open the project in Android Studio.
2. Allow Gradle synchronization to complete.
3. Start an Android emulator.
4. Click Run to launch the application.
